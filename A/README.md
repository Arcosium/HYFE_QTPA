# 팀원 A — 논문·자료 조사

논문과 자료 조사를 맡는다. 발표와 보고서는 팀장이 쓰고, A가 정리한 근거가 그 재료가 된다.
완성한 산출물은 이 폴더에 올리거나 회합 때 가져온다.

## 과제

| 블록 | 기간 | 할 일 | 산출물 |
|------|------|-------|--------|
| A1 | 9/7~9/20 (2주) | `papers/`의 논문 3편을 읽고 각 1쪽 요약. 무엇을 했나 / 어떻게 했나 / 우리 연구에 가져올 점, 세 칸만 채우면 된다(양식 제공). 중국 A주 논문 PDF는 SSRN에서 직접 내려받는다(`papers/README.md` 참고) | 논문 요약 3쪽 |
| A2 | 9/21~10/5 (2주) | 세 논문과 우리 연구의 차이를 비교표 한 장으로 정리. 요약을 바탕으로 이론 파트 초안 2~3쪽 — 문장이 거칠어도 된다, 다듬는 건 팀장 몫 | 비교표, 이론 초안 |
| A3 | 10/12~11/1 (3주) | 거래소 6곳(binance·bybit·hyperliquid·grvt·paradex·backpack)의 수수료·펀딩비를 공식 페이지에서 찾아 표로 정리 — 백테스트에 넣을 실제 비용 숫자. 이어서 최종보고서의 이론·관련연구 파트 초안 | 거래비용 조사표, 보고서 파트 초안 |

발표 주간(10/5~10/8, 11/2~11/9): 완성된 자료의 오탈자와 어색한 문장을 잡아준다.
