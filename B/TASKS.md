## 현재 진행

AI 도구와 함께 공개 샘플을 이용한 교육용 GBM 실습을 진행했고, 모델 학습·예측 저장·저장 예측의 AP 검산을 완료했다. 코드 실행과 자동 검산은 AI 도구가 수행했다. [실습 보고서](B1_PROGRESS_2026-09-14.md)에 설정·결과·해석 범위를 정리했다.

현재 구분은 **교육용 기준선 실습 완료 / 본 연구와 동일 조건의 공식 기준선 재현은 진행 전**이다. 공식 기준선 조건을 확인한 뒤 해당 설정의 성적표를 추가한다.

## B1 — 기준선 학습과 성적표

- [x] 공개 샘플·소스 버전 확보.
- [x] 6종목 샘플을 점검하고 첫 실습 대상 4종목 선택.
- [x] 15m·W120·H10·k2 교육용 GBM 학습 및 모델·예측 저장.
- [x] 급등·급락 AP를 저장 예측에서 재계산해 일치 확인.
- [x] 실습 결과와 본 연구 재현의 범위를 구분한 보고서 준비.
- [ ] 공식 제출 대상 확인: 15m 사건 기준선인지, 최신 4h·14일 상대방향 기준선인지.
- [ ] 공식 데이터 버전·종목 목록·분할·환경·실행 명령 확보.
- [ ] 공식 조건의 한 폴드를 실행하고 팀 결과와 대조.
- [ ] 차이 원인을 기록하고 팀이 지정한 범위까지 확대.

팀 확인 후의 완료 기준: 합의된 같은 조건에서 입력·정답·예측·성적표가 연결되고, 재현 여부와 차이를 설명할 수 있는 상태. 교육용 결과를 최신 CNN과의 동일 조건 비교에 넣지 않는다.

## B2 — 라벨 셔플 재학습

- [ ] 팀 제공 스크립트와 시험 대상 모델·데이터 확인.
- [ ] 무엇을 어느 범위에서 섞을지, 반복 수·시드·판정 방법을 실행 전에 기록.
- [ ] 정상 학습과 라벨 셔플 학습을 같은 평가 조건에서 실행.
- [ ] 성적과 사건 발생률·반복 간 편차를 표로 정리.
- [ ] 성능이 유지되면 누수·셔플 구현·평가 방식 등 원인 조사.

라벨을 섞어 다시 학습하는 시험과, 기존 예측 점수를 섞어 매매하는 대조는 별개다. 저장소의 기존 셔플 결과를 재사용할 경우 대상·방법·버전을 확인한다. 성능 붕괴만으로 모든 종류의 누수가 없다고 결론내리지 않는다.

## B3 — 백테스트 점검과 일지

- [ ] 팀 체크리스트를 받고 항목별로 통과·문제·미확인 및 근거 위치 기록.
- [ ] 입력 관측 시각, 정답 시각, 학습/검증/시험 경계 점검.
- [ ] 진입·청산 가격, 수수료·펀딩·슬리피지 적용 확인.
- [ ] 동시 보유·자본 배분·중첩 날짜의 계좌 처리 확인.
- [ ] 모의매매에서 신호·가상 체결·비용·오류·백테스트와의 차이 기록.
- [ ] 관측 기간·거래 수와 함께 결과를 요약.

추가 검토 후보: 홀드아웃의 실제 사용 이력, 같은 정보·같은 표본·같은 반복 수의 모델 비교, 원시 예측→계좌 재현. 팀과 우선순위를 맞춰 진행한다.
