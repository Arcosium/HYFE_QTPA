# 팀원 B — 숫자 확인

결과가 진짜인지 확인하는 자리다. 어려운 코드는 팀장이 만들어 주고, B는 돌려보고 기록한다.
완성한 산출물은 이 폴더에 올리거나 회합 때 가져온다.

## 과제

| 블록 | 기간 | 할 일 | 산출물 |
|------|------|-------|--------|
| B1 | 9/7~9/20 (2주) | 팀장이 준 정리된 데이터로 기준선 모델(GBM: 표 형태 데이터용 기본 머신러닝) 학습. 우리 이미지 모델이 이 간단한 모델보다 나은지 재는 비교 대상이 된다. 연습은 `data/sample/`로 시작하면 된다 | 기준선 성적표 |
| B2 | 9/21~10/5 (2주) | 정답표를 일부러 섞어 다시 학습시키는 시험 실행 — 섞었는데도 점수가 나오면 어딘가 정보가 샌 것. 실행 스크립트는 팀장 제공, B는 돌리고 결과를 표로 기록 | 섞기 시험 결과표 |
| B3 | 10/12~11/1 (3주) | 백테스트 점검: 미래 정보를 미리 본 곳이 없는지 체크리스트로 항목별 확인(체크리스트 제공). 10월 말부터 모의 매매 일지: 하루 5분, 백테스트 예상과 실제 결과가 얼마나 다른지 기록 | 점검 기록, 모의 매매 일지 |

발표 주간(10/5~10/8, 11/2~11/9): 슬라이드의 숫자와 원본 표의 숫자가 같은지 대조한다.
