# 팀원 C — 데이터·기록

데이터 상태 점검과 기록을 맡는다. 꼼꼼함이 무기인 자리다.
완성한 산출물은 이 폴더에 올리거나 회합 때 가져온다.

## 과제

| 블록 | 기간 | 할 일 | 산출물 |
|------|------|-------|--------|
| C1 | 9/7~9/20 (2주) | 팀장이 준 점검 스크립트를 돌려 코인별·월별로 데이터가 빈 곳이 있는지 표로 정리. 분석에서 뺄 목록 확정: 코인이 아닌 것(토큰화 주식·원자재)과 집계 방식이 다른 종목. `data/coverage.csv`가 출발점이다 | 데이터 점검표, 제외 목록 |
| C2 | 9/21~10/5 (2주) | 자동 생성된 차트 이미지 눈검사: 데이터셋마다 샘플 50장씩, 겹침·빈 이미지·이상한 축을 체크리스트로 확인. 실험 기록 시트 관리: 어떤 설정으로 몇 점이 나왔는지 한 줄씩 | 눈검사 기록, 실험 기록 시트 |
| C3 | 10/12~11/1 (3주) | 결과 차트 만들기: 잔고 곡선, 최대 손실 폭 등. 숫자와 양식은 팀장이 주고 C는 보기 좋게 그린다. 발표에 쓸 그림·표 소재 정리 | 결과 차트, 그림 소재 모음 |
